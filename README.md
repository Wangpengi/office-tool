# 📝 论文一键智能排版工具 (office-tool)

> 一款轻量、隐私安全、开箱即用的纯前端学术论文与公文智能排版辅助工具。无需安装插件或宏，自动提取要求中的字体、字号、行距，智能匹配文章各级结构，生成后一键复制即可直接粘贴进 Microsoft Word 或 WPS 中成型。

---

## ✨ 核心亮点

- ⚡ **使用方法极简**：保持经典的“三步走”流程（① 粘贴格式要求 ➔ ② 粘贴论文纯文本 ➔ ③ 预览并一键复制），没有任何学习成本。
- 🎯 **精准规则解析**：
  - 彻底解决关键词覆盖冲突（优先匹配“三级标题”、“二级标题”、“一级标题”，再匹配“副标题”、“标题”）；
  - 全面支持常用字号（初号至八号、小初、小一至小五、1号至5号、12pt/14磅等精确磅值）；
  - 覆盖丰富行距（固定值xx磅、xx倍行距、单倍/双倍行距）；
  - 适配各种缩进表述（首行缩进2字符、顶格左对齐、悬挂缩进等）。
- 📑 **多层级智能文章嗅探**：
  - 智能识别论文主标题与副标题；
  - 识别中文与英文摘要（`摘要`、`Abstract`）及关键词（`关键词`、`Keywords`）；
  - 识别文科传统标号（`一、`、`（一）`）、理工科阿拉伯标号（`1.`、`1.1`、`1.1.1`）以及章节制（`第一章`）；
  - 自动识别参考文献并应用标准悬挂缩进；
  - 智能排版致谢与声明等尾部段落。
- 🖥️ **仿真 A4 纸张美化预览**：拥有逼真的 A4 论文排版质感与真实页边距视觉反馈。
- 📋 **Word 复合字体与格式无缝兼容**：
  - 中文自动匹配宋体/黑体，英文字符与阿拉伯数字自动匹配 `Times New Roman`；
  - 严谨支持微软 Word 专有的 `mso-line-height-rule: exactly` 与 `mso-char-indent-count` 标准。
- 🔒 **100% 隐私安全与离线可用**：
  - 纯客户端前端计算，任何文本内容均**不上传至任何第三方服务器**，杜绝论文外泄风险；
  - 单个轻量 HTML 文件，双击即可直接在浏览器中打开使用。

---

## 🚀 快速使用说明

1. 直接用任意现代浏览器（Chrome、Edge、Safari、Firefox）双击打开项目中的 `index.html`；
2. **第一步**：在左上方输入框粘贴老师或学校给出的【格式要求】（或点击“填入示例”快速体验）；
3. **第二步**：在左下方输入框粘贴你的【论文纯文本】；
4. **第三步**：点击底部的 **【🚀 一键生成并复制到 Word】** 按钮；
5. 打开空白 **Microsoft Word** 或 **WPS** 文档，直接按下快捷键 **`Ctrl + V`**（Mac 电脑按 **`Cmd + V`**）粘贴即可！

---

## 🛠️ 技术实现原理

1. **规则抽取引擎**：基于中文分词加权与长词优先的语义绑定算法，避免子串冲突；
2. **文本结构判定**：正则与上下文状态机识别章节与段落级别；
3. **Word 兼容渲染**：动态构建包含 `mso-ascii-font-family`、`mso-fareast-font-family`、`mso-line-height-rule` 等内联样式的富文本数据；
4. **双模剪贴板写入**：优先调用 `navigator.clipboard.write([new ClipboardItem(...)])` 写入 `text/html` 富文本，并提供 DOM 选区降级兜底方案，确保 100% 复制成功。
